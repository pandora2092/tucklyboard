# Save

Личное избранное в Telegram: ссылки, заметки, фото и видео. NestJS + PostgreSQL + MinIO/S3; Mini App на React с Telegram WebApp SDK.

## Локальный запуск

Требуются Node.js 22+ и Docker с Compose.

```sh
cp .env.example .env
npm install
docker compose up -d
npm run db:generate
npm run db:push
npm run dev:api
```

В другом терминале:

```sh
npm run dev:web
```

Mini App: http://localhost:5173. API: http://localhost:3000/api/health. Консоль MinIO: http://localhost:9001 (локальные учётные данные в `.env.example`). MinIO собирается из исходников закреплённого [официального релиза RELEASE.2025-10-15T17-29-55Z](https://github.com/minio/minio/releases/tag/RELEASE.2025-10-15T17-29-55Z): официальный готовый образ недоступен в проверенных реестрах. Первая сборка требует сети и занимает больше времени. API создаёт bucket при первой загрузке файла. Для S3 CORS задаётся через API, а для MinIO — через `MINIO_API_CORS_ALLOW_ORIGIN` в Compose. Ссылки и заметки работают при временно недоступном S3. Если используете внешний S3, учётной записи нужны права настройки bucket либо перенесите эту настройку в инфраструктуру.

`DEV_AUTH=true` включает одного локального пользователя без Telegram только вне production. Для реального запуска установите `DEV_AUTH=false`, `NODE_ENV=production`, задайте `BOT_TOKEN`, `MINI_APP_URL` и `WEB_ORIGIN`. Для запуска API внутри контейнера задайте `HTTP_HOST=0.0.0.0`. Mini App должна открываться по HTTPS. Настройте кнопку меню бота через BotFather. Бот получает сообщения через long polling: запускайте только один экземпляр API. Если для бота ранее настроен webhook, удалите его перед polling.

Браузер должен иметь доступ к `S3_ENDPOINT`: этот адрес попадает в подписанные ссылки загрузки и просмотра. Для production используйте HTTPS endpoint и отдельные секреты, а не локальные значения из примера. Не открывайте локальный dev-сервер в интернет с включённым `DEV_AUTH`.

## Реализовано

- Проверка подписи и срока Telegram initData на сервере.
- Изолированные данные пользователей; авторизация каждой операции.
- Лента с пагинацией, входящие, коллекции, теги, фильтр типа и поиск по названию, тексту и домену.
- Создание, редактирование и удаление карточек.
- Загрузка фото/видео до 20 МБ напрямую в приватный S3 через подписанный URL.
- Просмотр медиа через временные ссылки.
- Бот принимает текст, ссылки, фотографии, видео и пересланные сообщения; повторная обработка сообщения не создаёт новую карточку.
- Одинаковая ссылка, добавленная через Mini App, возвращает существующую карточку.
- Адаптивный интерфейс без демонстрационных записей.

## Границы первой версии

Ссылки сохраняются без автоматического получения Open Graph. Telegram-альбом пока создаёт несколько карточек. Поиск — `contains`, без полнотекстового индекса. Нет общих пространств, фонового воркера, массовых действий, восстановления удалённого и квот подписки. Цветовая схема пока светлая. Произвольные файлы не поддерживаются. Бот скачивает медиа в память с лимитом 20 МБ; потоковая обработка нужна до увеличения лимита.

Загрузка, которую пользователь не подтвердил созданием карточки, оставляет объект в S3. Перед публичным запуском необходима очистка таких объектов и независимая проверка формата файла. Подписанные ссылки живут 15 минут: обновите ленту, если медиа перестали открываться.

## Следующие этапы

1. Добавить SQL-миграцию для production вместо `db push`, интеграционные тесты доступа и CI.
2. Вынести обработку ссылок и медиа в worker с очередью PostgreSQL; Open Graph с защитой от SSRF, миниатюры, объединение Telegram-альбомов.
3. Добавить Space, SpaceMember, Invite; перенести коллекции и карточки в пространства, проверить роли.
4. Нормализовать URL, унифицировать дедупликацию бота и Mini App; добавить полнотекстовый поиск, фильтр источника и массовые действия.
5. Тема Telegram, доступность, восстановление загрузок, сбор ошибок, резервное копирование и очистка файлов.
6. Учёт объёма, квоты и только затем платная подписка.

Не размещайте production-данные в локальных Docker volumes без резервного копирования.

Аудит npm: Zod обновлён; у Prisma CLI 6 остаётся предупреждение о транзитивном `deepmerge-ts`. Не передавайте недоверенную конфигурацию Prisma CLI. Миграцию Prisma на новый major нужно проверить отдельно.

## Состояние проверки первой версии

Проверены сборка обоих приложений, 4 теста Telegram-подписи, сохранение ссылки через UI и сквозной тест API с реальным PostgreSQL и временным MinIO `RELEASE.2024-08-26T15-33-07Z`. Тест включает изоляцию пользователей и загрузку, чтение и удаление файла по подписанным S3-ссылкам. Старый образ использовался только для изолированной проверки, в Compose он не включён. Сборка целевого MinIO из исходников была прервана на скачивании зависимостей и пока не проверена до конца. Реальный Telegram-бот без `BOT_TOKEN` не проверялся.
